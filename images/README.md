images/ — Görseller klasörü

Bu klasör, rehber içinde referans verilen ekran görüntüleri ve diyagramlar için kullanılır.

Önerilen dosya isimlendirmesi:
- screenshot-1.png — xrandr / hyprctl çıktısı
- monitors-config-example.png — monitors.lua örneği
- before-after-hz.png — önce / sonra karşılaştırma

Görselleri eklerken:
- PNG veya JPEG kullanın (PNG tercih edilir for screenshots).
- Dosya adlarında boşluk kullanmayın; küçük harf ve `-` tercih edin.
- README içinde markdown ile referans verin: `![description](images/screenshot-1.png)`
